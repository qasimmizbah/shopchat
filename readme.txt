Boost WooCommerce sales with WhatsApp Order Notifications, Abandoned Cart Recovery, Floating Customer Chat, and Review Boosters.

== Description ==

**ShopChat** is an all-in-one customer engagement and recovery suite designed specifically for WooCommerce store owners.

WhatsApp messages boast an incredible **90%+ open rate** compared to traditional emails. ShopChat gives your store the power to communicate with shoppers via WhatsApp instantly.

### 🌟 Key Features

* **100% Free 1-Click Messaging (Default):** Zero monthly fees, zero Meta API setup, zero per-message costs. Send order notifications and cart recovery links directly with 1 click from your WordPress admin.
* **Automated Meta Cloud API Support (Optional):** Ready for high-volume stores needing automated background dispatch via the official WhatsApp Business Platform.
* **Storefront Floating WhatsApp Widget:** Beautiful, customizable chat bubble with agent name, online status, and prefilled product inquiry on product detail pages.
* **Abandoned Cart Capture & Recovery:** Automatically captures guest shopper contact info on checkout field change. Send 1-click cart restore links with items repopulated.
* **Dynamic Template Engine with Live Phone Simulator:** Customize order status alerts (Processing, Completed, Shipped, etc.) with dynamic tags (`{customer_name}`, `{order_id}`, `{order_total}`) and preview them in a realistic WhatsApp smartphone mockup.
* **Post-Purchase Review Booster:** Generate one-click WhatsApp review requests to increase product ratings.
* **High-Performance Order Storage (HPOS) Ready:** 100% compatible with modern WooCommerce HPOS and Classic custom post types.

== Installation ==

1. Upload the `shopchat` folder to the `/wp-content/plugins/` directory, or install the plugin directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to **ShopChat** in your WordPress admin menu.
4. Enter your store's WhatsApp Business number and save.
5. Customize your order templates and enjoy higher conversions!

== Frequently Asked Questions ==

= Is this plugin completely free to use? =
Yes! By default, ShopChat uses our 1-Click direct send technology (`wa.me`). You do not need to pay any monthly subscriptions, credit cards, or Meta API charges.

= Do I need a Meta Developer Account? =
No. You can use any existing WhatsApp or WhatsApp Business number. A Meta Cloud API connection is completely optional for stores that prefer background automation.

= Does it work with guest checkout? =
Yes. Our checkout listener detects when guest shoppers enter their phone number or email, allowing you to recover abandoned carts even before an account is registered.

= Is ShopChat compatible with WooCommerce HPOS? =
Yes, ShopChat fully declares and implements High-Performance Order Storage (HPOS) compatibility.
